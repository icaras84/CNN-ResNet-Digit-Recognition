# CNN & ResNet Digit Recognizer

To run this project locally, the following dependencies must be installed:
- `matplotlib`
- `seaborn`
- `pandas`
- `pytorch`


The following installs these libraries locally:
```commandline
pip install matplot 
pip install seaborn
pip install pandas
```

For PyTorch, visit their [official website](https://pytorch.org/get-started/locally/)
and select the options for Python. If your system has an NVIDIA discrete graphics card,
then please select the option for the latest CUDA version you have.
